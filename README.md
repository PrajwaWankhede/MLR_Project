# MLR_Project
# 🚀 Multiple Linear Regression Profit Prediction

A professional Machine Learning web application developed using Flask and Multiple Linear Regression to predict company profit based on business expenditure data.

This project demonstrates the integration of Machine Learning models with Flask backend development and a responsive frontend interface.

---

## 📌 Features

✔️ Predicts company profit using Multiple Linear Regression  
✔️ User-friendly web interface  
✔️ Flask backend integration  
✔️ Real-time prediction system  
✔️ Responsive frontend using Bootstrap  
✔️ Deployable using Gunicorn & Procfile

---

## 📊 Input Features

| Feature | Description |
|---------|-------------|
| R&D Spend | Research and Development expenses |
| Administration | Administrative expenses |
| Marketing Spend | Marketing expenses |
| State | Company location/state |

---

## 🧠 Project Workflow

1. User enters expenditure details.
2. Flask receives the input values.
3. Machine Learning model predicts the profit.
4. Predicted output is displayed on the webpage.
